# National Data Opt-Out integration spike — 10 October 2026

**Decision: keep National Data Opt-Out out of the public Parliamentary Lens release.** A local NHS England geography CSV was checked at practice grain, but its latest date is 5 August 2026 and its list sizes are a static March 2023 snapshot. It does **not** support observed constituency-resident opt-out rates or contemporaneous 2026 practice population rates. This PR includes only an offline research adapter, local aggregate validation and synthetic tests; `web/` contains no opt-out values or links to the research output.

NHS England describes the national preference as a choice about confidential patient data use for **research and planning beyond individual care**. It is not a measure of trust, willingness to participate in research, dementia diagnosis, clinical quality, or service performance. The [dashboard metadata](https://digital.nhs.uk/dashboards/national-data-opt-out-open-data) defines the opt-out count as unique NHS numbers excluding deceased people and `Opt-out rate` as a ratio to `List Size`. The source project's `AGENTS.md` and streaming extractor document that **the weekly export repeats March 2023 practice list sizes on later dates**. Thus a 2026 row date does not make its list-size denominator contemporaneous. The separate April 2026 GP registration denominator used by that project is outside this adapter and must be validated independently before making a 2026 practice population-rate claim. The spine's 1 July 2026 extract is also not a drop-in replacement for either denominator.

The [NHS England site terms](https://digital.nhs.uk/about-nhs-digital/terms-and-conditions) generally apply the current Open Government Licence to NHS England content unless otherwise stated, with attribution and no implied endorsement. Confirm the actual CSV's notices before any redistribution. The historical derived files in a private repository are not a new public licence grant.

## Tested ODS join, with its limit

The offline adapter in [`spikes/opt_out.py`](../spikes/opt_out.py) reads a locally obtained NHS England geography CSV at **one explicit date**, groups `Practice Code × Date × Measure Names`, hashes the source in chunks, and joins only to `organisation_parliamentary_profile.parquet` on the exact ODS code. It uses `Opt-out`, `List size`, and `Opt-out rate`, excludes the separate `Deceased` measure, rejects duplicate measure keys, and retains unknown/suppressed/zero as different states. Finite count/rate inconsistencies and apparent values over 100% are **retained with anomaly flags and aggregate counts**, never clipped or treated as individual choice probabilities; non-finite rates are rejected as invalid source values. Source URL, file hash, full date range and row count are recorded; missing original version/retrieval metadata have explicit caveats. It emits a bounded local practice sample and reason counts. A PCON code, when present, is named `spine_address_pcon24cd_context_only`; the adapter emits **no constituency opt-out numerator, denominator, or rate**.

The synthetic test fixture has four practice-code rows at 5 August 2026: one mapped GP address, one unmapped GP address, one code that maps to a non-GP spine organisation, and one code absent from the spine. Its join reason counts are **1 each**. One official count is `0`, another is suppressed (`*`), and an absent list size is unknown rather than zero. These numbers are illustrative test data, not NHS statistics.

The existing ignored local `opt_out_data/geography.csv` was read in place on 10 October 2026, without copying or committing it. Its local file size is **774,657,879 bytes** and SHA-256 is **`90fab8d71197436e9970f9dfdf0acaedfadefd20f6eaf2ef6e8eccb1c5c33cd6`**. The file has the expected 15 columns, **3,776,724 data rows** and **147 distinct dates** from 2 August 2023 to 5 August 2026. The bounded **5 August 2026** selection has **25,692 measure rows** for **6,423 practice codes**. The source URL was present in the file's local download metadata; the original export version and retrieval time were not, so the file creation/modification times are not represented as source retrieval evidence. Join against the accepted 10 October 2026 v0.3 profile:

| Join reason | Codes |
|---|---:|
| Matched GP with mapped address | 6,412 |
| Absent from spine snapshot | 11 |
| Duplicated source practice code | 0 |
| Total selected-date codes | 6,423 |

All 6,423 selected practice codes have an available count and static list size; 6,422 have an available source rate and one rate is unknown. **One count exceeds its March 2023 list size**; no rate above 100% or count/rate disagreement was flagged in this selected week. These are source quality observations, not probabilities or a corrected 2026 rate. The 11 unmatched codes need code-history review; name matching or silent code substitution is prohibited. The 99.8% code match does not validate contemporary denominators, ICB assignments, patient residence, or a public release. A release candidate needs an independently dated current download and a separately justified rate denominator.

## Recommendation and next gate

1. Keep the present public site to v0.3 geography, membership, ODS and GP registrations. **Do not add opt-out data in this PR.**
2. Retain the local CSV hash and aggregate QA above as a reproducible research baseline. For a future practice release, acquire a current official geography export with its original download timestamp, source version/date, notice and hash. Recheck join reasons, anomalies, rate scale, deceased exclusions and code history. Use a separately verified contemporary list-size denominator if claiming a 2026 population rate. Inspect small-cell and privacy requirements before a practice page is considered.
3. If a practice-context module is proposed, define it in its own dated release asset and editorial review; describe a practice's *registered* population, not the constituency's residents. Do not treat Type 1 as the National Data Opt-Out series.
4. A constituency-resident product needs an independently published observed resident-geography source with compatible date and boundary, or a separately approved formal model with uncertainty and non-identifiability stated. Neither exists as a publishable PCON24 result in this assessment.

Reproduce the safe fixture: `python -m pytest -q tests/test_opt_out_spike.py`. For the existing local file, run `python -m spikes.opt_out --geography-csv '/path/to/public-sentiment/opt_out_data/geography.csv' --profiles data/processed/organisation_parliamentary_profile.parquet --date 2026-08-05 --source-url https://tabanalytics.data.england.nhs.uk/t/Public/views/NationalDataOptOut/geography.csv --list-size-vintage 'March 2023 static snapshot (source-project validation)'`. Supply `--source-version` and `--retrieved-at` only if the original metadata is known; otherwise the report explicitly records both as unavailable. The default report is ignored under `data/opt-out-spike/`; it is a research sample, not a website asset.
